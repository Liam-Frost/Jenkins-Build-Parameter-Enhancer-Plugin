语法
每行一条日程：
cron 表达式 % Preset=预设名[; KEY=value; ...]
  • 以 # 开头的行是注释。
  • 单独一行 TZ=Asia/Shanghai（任意 IANA 时区）会修改其后各行的时区。
  • cron 表达式遵循 Jenkins 标准语法，支持用 H 分散负载。
  • Preset=名字 必填，名字必须与某个共享预设完全一致。
  • 额外的 KEY=value 覆盖会覆盖预设里的值。参数值不能包含 ;。
  • 密码参数不能在这里覆盖（值会以明文存入 config.xml）。
参数值的优先级
参数默认值 → 预设值 → 本行覆盖值。
如果预设值或覆盖值非法（例如某个选项已被删除），构建将被跳过，错误会显示在任务页面的 预设日程块中。
示例
H 2 * * * % Preset=Nightly
H 12 * * 1-5 % Preset=Daily smoke; BRANCH=develop
Pipeline 写法： 
triggers { presetCron('H 2 * * * % Preset=Nightly') }
复制任务时
所有日程行会自动被注释掉。去掉 # 即可重新启用。
