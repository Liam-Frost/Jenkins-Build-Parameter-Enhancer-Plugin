Syntax
Each line is one schedule entry:
cron-expression % Preset=name[; KEY=value; ...]
  • Lines starting with # are comments.
  • TZ=Europe/Berlin (or any IANA timezone) on its own line sets the timezone for following entries.
  • Cron expressions follow standard Jenkins syntax and support the H token to distribute load.
  • Preset=name is required. The name must match a shared preset exactly.
  • Extra KEY=value overrides override preset values. Parameter values cannot contain ;.
  • Password parameters cannot be overridden here (the value would be stored in plain text in config.xml).
Parameter values
Priority: parameter default → preset value → override from this spec.
If a preset value or override is invalid (e.g., a choice that no longer exists), the build is skipped and the error is shown in the Preset Schedules box on the job page.
Examples
H 2 * * * % Preset=Nightly
H 12 * * 1-5 % Preset=Daily smoke; BRANCH=develop
Pipeline: 
triggers { presetCron('H 2 * * * % Preset=Nightly') }
When a job is copied
All schedule lines are commented out automatically. Remove the # to re-enable them.
